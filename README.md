# BeCastedFilms
BeCastedFilms is a non-profit independent film community based in Olongapo City, Philippines, founded by a 14-year-old to empower teenage filmmakers, actors, and creatives.
# 🎬 Join BeCastedFilms!
BeCastedFilms is a non-profit independent film community dedicated to connecting passionate teenagers in Olongapo City, Philippines. Whether you want to act, direct, write, or work behind the camera, you are welcome here!
